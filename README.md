# 🏎️ PITWALL — GP de São Paulo (Interlagos)

 temática de Fórmula 1 desenvolvida como atividade prática de **HTML5** e **CSS3**, simulando a página oficial de informações, classificação e venda de ingressos para o Grande Prêmio de São Paulo no Autódromo de Interlagos.

---

## 📋 Sobre o Projeto

O **PITWALL** é uma aplicação front-end estática focada na estruturação semântica e estilização moderna inspirado no universo do automobilismo. A página reúne informações do circuito, destaques do grid, tabela de campeonato e um formulário completo de reserva de ingressos.
